# ProjectForge

A student project discovery platform where users can explore, filter, and generate project ideas.

## Features
- Browse and filter projects by difficulty, dev time, domain, and technologies
- AI-powered "Generate an Idea" feature with match-percentage reasoning
- Save projects for later
- Resume-ready project descriptions

## Live Demo
https://projectforge-web-app-ypcb.bolt.host

## Built With
TypeScript, JavaScript, CSS, Vite, Supabase
